# Данные портфолио

- `projects.js`: шесть видеопроектов в существующем порядке. `media` — главное видео, `gallery` — дополнительные файлы. Главное видео автоматически включается в мини-галерею первым.
- `static-projects.js`: четыре самостоятельные статичные работы. Замените `media: null` на путь к изображению, задайте название и описание. Сейчас все четыре записи — явные заглушки; `project01-3.jpg` остаётся в проекте Taulan.
- `3d-projects.js`: модели Sketchfab. Первые шесть записей показываются в горизонтальной 3D-галерее, остальные сохранены. Необязательное поле `preview: "assets/model.jpg"` задаёт локальную обложку; иначе сайт запрашивает миниатюру Sketchfab. По клику модель открывается внутри сайта: iframe использует исходную ссылку `sketchfab` с `/embed` и её параметрами. Viewer создаётся только при открытии и удаляется при закрытии. Позиция прокрутки и карточка сохраняются.

Пути к медиа задаются относительно корня сайта. В `gallery` можно добавлять любое количество изображений и видео, без требований к именам файлов. Поддерживаются строковые пути и объекты `{src: "assets/file.mp4", type: "video", poster: "assets/poster.jpg"}`. Для изображений используйте `type: "image"`; необязательное `alt` задаёт текст изображения. Внутри мини-галереи пропорции сохраняются, обложки карточек заполняют свою область с кадрированием.

Пример записи статичной работы:

```js
{id: 'still01', title: 'Название', category: 'Stills',
 media: 'assets/still01.jpg', description: 'Описание работы.',
 gallery: ['assets/still01-detail.jpg', 'assets/still01-process.mp4']}
```

Скролл и длина галерей рассчитываются из количества записей. Колесо и вертикальный свайп используют обычную прокрутку документа. Точки под галереей также позволяют перейти к проекту. Мини-галерея закрывается кнопкой, Escape или кликом по внешнему фону; позиция страницы и фокус восстанавливаются.

`motion-projects.js` — старый неиспользуемый список, оставлен для совместимости с историей проекта. `sync-project-galleries.ps1` — необязательная прежняя утилита автоматического заполнения дополнительных файлов по шаблону `projectNN-N`; ручные списки `gallery` позволяют использовать любые имена.

## Локальный запуск

Из корня проекта: `python -m http.server 4173 --bind 127.0.0.1`, затем открыть http://127.0.0.1:4173/ . Сборка и зависимости для самого сайта не нужны. Проверочные инструменты и снимки хранятся в игнорируемых `.local-tools/` и `.local-preview/`.

Все три галереи используют общий пошаговый контроллер: небольшой импульс колеса или вертикальный свайп переключает на один соседний проект. Инерция одного жеста не пролистывает дополнительные карточки. Центральная карточка увеличена, боковые уменьшены. Переходы сглажены (150 мс с учётом времени кадра), конечная позиция всегда соответствует целому индексу проекта, в том числе при перемещении полосы прокрутки.

Во время удержания галереи колесо/свайпы управляют карточками; на первом и последнем проекте следующий жест в соответствующем направлении переходит к соседнему разделу. За пределами галерей страница прокручивается обычно. Точки выбирают конкретную карточку. Arrow Up/Down и Page Up/Down также переключают проекты, если фокус не находится на интерактивном элементе. Настройка reduced motion отключает анимацию.

## Фоновое видео и интерактивные модели

`assets/hero.mp4` — общий фиксированный фон под галереями и остальным содержимым. Отдельного вступительного блока нет. `background-video.js` связывает время видео с общей позицией страницы: вниз — вперёд, вверх — назад. Видео без звука, не проигрывается самостоятельно; при остановке скролла и при открытии мини-галереи кадр сохраняется. Файл предварительно загружается целиком (сейчас около 3.2 МБ) для перемотки на локальном сервере без HTTP Range.

Встроенный Sketchfab viewer теперь получает `autostart=1`: клик по карточке сразу начинает загрузку интерактивной модели, без дополнительной кнопки Play. Отдельная ссылка Open on Sketchfab открывает страницу модели в новой вкладке. Параметр описан в официальной документации: https://sketchfab.com/developers/viewer/initialization .
